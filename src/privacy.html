Privacy

Effective 22 November 2026.

就腳 runs in your browser. It has no account system and no application backend.

What stays on your device

The app stores current people, settings, saved profiles, locale, and a small geocoder cache in browser localStorage. Keys begin with hkfair.v2.. A saved person includes a name, start place, and per-person walk tolerance. Settings include the includeHeadway parameter (on by default), which controls whether interchange headway waits are charged and shown for the whole trip.

Share links put the current scenario in the URL fragment, including the includeHeadway setting. Walk tolerance stays with each person. Anyone who receives the link can see that scenario. Do not put sensitive information into people names or start places if you plan to share.

Clear site data in your browser to remove stored values.

External requests

The app sends place-search queries to Photon and requests vector map tiles from OpenFreeMap. Those providers may see your IP address and request metadata under their own policies. 就腳 does not receive those logs.

The app does not use analytics, advertising, cookies, or tracking pixels. The map also requests font glyph files from tiles.openfreemap.org. Icons are bundled locally.

Offline cache

A service worker caches app assets, local data files, and translation catalogues so the app can load again later. Clearing site data removes this cache.

Diagnostics export

Turning on Beta features reveals a Diagnostics button in the footer. Pressing it downloads a JSON file and attempts to copy the same text to your clipboard; this can fail if the browser denies clipboard access. The file contains your people's names, start places (including coordinates), routes, fares, settings, and the current page URL. It also contains the areas and hotspots shown on the map (areas, hotspots), the current selection and pinned point (selection, selectedArea, freePoint), and the solve key (solveKey). The app does not send this file anywhere; only you decide what to do with it.
